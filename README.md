# Safari 网页工具：视频嗅探 · 广告过滤 · 阅读模式 · 常用站点

视频嗅探：在 iPhone / iPad 的 Safari 网页上查看视频名称、时长和链接，并一键复制给下载工具。嗅探到视频只点亮悬浮球下方的 ▶ 小圆钮，面板不会自动弹出。与广告过滤、阅读模式、常用站点共用一个小巧、可拖动的悬浮入口。

**前提与限制：** Safari 不能直接执行一个普通的 `.js` 文件，需要安装并启用 Userscripts 等脚本管理扩展。本脚本按现有项目的 **Userscripts + `@grant none`** 方式编写。通用提取不保证覆盖所有网站，不绕过登录、付费权限或 DRM。请仅下载你有权保存的内容。

**从旧版更新：** 请同时替换 [视频嗅探](./视频嗅探.user.js)（1.3.0）、[广告过滤](./广告过滤.user.js)（1.5.1）和 [阅读模式](./阅读模式.user.js)（3.0.0），然后刷新网页。不要保留旧版副本同时启用，否则旧脚本仍会显示各自的按钮。两个脚本仍可独立安装；同时启用新版时会自动合并入口，不需要额外安装第三个脚本。原来保存的隐藏规则、广告开关和视频筛选设置继续沿用。

## 安装并复制第一个链接

1. 安装并打开 iOS / iPadOS 的 **Userscripts**，设置脚本目录。
2. 把 [视频嗅探.user.js](./视频嗅探.user.js) 放到该目录，确认扩展中已识别并启用这个脚本。如需合并广告过滤功能，也放入新版 [广告过滤.user.js](./广告过滤.user.js)。保留 `.user.js` 后缀，不要额外加 `.txt`。
3. 在系统设置的 **Safari → 扩展 → Userscripts** 中启用扩展，允许它访问需要提取的网站。不同系统版本也可能将 Safari 放在“设置 → App”中。
4. 用 Safari 打开目标网页并刷新。轻点默认位于右下角的 **小圆点 ⋮**，再选择 **“视频链接 · N”**。
5. 如果没有视频入口，先在网页上播放几秒，或向下滚动加载视频，检测到后会自动出现。如果已有入口但列表为空，可以打开面板点击 **“重新扫描”** 或调整筛选。进入系统全屏播放器时，先退出全屏返回网页。
6. 核对片名、时长、格式和域名，点击该条目的 **“复制链接”**。需要批量复制时，使用 **“复制显示链接”**，每行一个地址。

如果 Safari 拒绝自动写入剪贴板，会显示手动复制文本框：长按文本框，选择“全选 → 复制”。每条记录的“查看完整链接 / 手动复制”也能展开原始地址。

## 移动入口并使用广告过滤

- **更小：** 平时只显示直径 **32px** 的圆点；装了隐藏干扰项脚本时，上下各多一个 **28px** 的箭头小钮。每个按钮都保留 **44px** 的透明触摸区域，避免缩小后难以点中。功能名称和数量放在展开菜单里，不再左右各占一个按钮。
- **直接拖动：** 用手指或鼠标按住圆点拖到合适位置，松手不会打开菜单；轻点才展开菜单。点击页面其他位置可以收起菜单。
- **回顶部 / 到底部：** 隐藏干扰项脚本会在圆点上下各挂一个箭头：轻点 ↑ 直接滚到网页最顶部，轻点 ↓ 滚到最底部；正文放在自己滚动容器里的网页也能识别。只装视频助手时没有这两个按钮。按住任意一个按钮拖动，整组一起移动。
- **记住位置：** 按网站来源保存在 `localStorage`，刷新后恢复。横竖屏、窗口和可视区域变化时会限制在屏幕内；菜单也会避开边缘。网站不允许保存时，本次页面仍然可以拖动。
- **按需显示：** 检测到播放器（包括无直链或 `blob:` 播放器）、媒体链接或可识别视频资源后，才显示视频入口和 ▶ 小圆钮；面板绝不自动弹出，只在你点小圆钮或菜单项时打开。动态加载的视频会自动出现；移除播放器/媒体节点或切换到无视频的页面后会收起相应入口。普通的未知跨域 iframe 不会被直接当成视频。
- **没有视频：** 同时安装广告脚本时，小圆点只提供广告功能；仅安装视频脚本时，整个圆点隐藏。若视频确实存在、只是全部被时长等条件过滤，仍保留视频入口，方便修改设置，不会因为显示数量为 0 就无法恢复。

展开菜单后：

| 菜单项 | 操作 |
| --- | --- |
| 视频嗅探 · N | 查看、筛选及复制当前网页的视频链接；悬浮球下方的 ▶ 小圆钮点亮表示已嗅探到，角标是可复制条数，点它也能打开面板 |
| 点选隐藏 | 点击网页上的干扰元素，然后选择“上一层”“隐藏”或“取消”；圆点变为 **×**，轻点它可退出选择模式 |
| 广告过滤 / 已隐藏项 | 开关自动广告过滤，恢复某条已隐藏规则，或清空本站的手动规则 |

旧版广告悬浮球的“长按管理”改为菜单里的明确按钮，不再与拖动冲突。自动广告过滤仍在后台生效，无需打开菜单。桌面端也可按 `Esc` 收起菜单、面板或退出选择模式。

## 设置数量、时长和广告过滤

点击面板右上角 **“设置”**，调整后点击 **“保存设置”**。

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 最多显示链接数 | 20 | 可设 1–200；批量复制只包含当前显示的这些链接 |
| 最低时长（秒） | 60 | 仅过滤**已知时长**低于门槛的视频；恰好 60 秒保留；设 0 表示不限 |
| 隐藏时长未知 / 直播的视频 | 关闭 | 未知时长默认保留并明确标注，**不代表视频达到最低时长**；要求严格只保留长视频时请开启 |
| 过滤疑似广告 | 开启 | 根据常见广告域名、路径标记、播放器的广告容器判断；不是百分百准确，可关闭排查误伤 |
| 额外排除关键词 / 域名 | 空 | 用逗号或换行分隔，最多 50 个，匹配链接与名称；不区分大小写，不使用正则；独立于广告开关生效 |
| 排序 | 按发现顺序 | 可改为时长从长到短；未知时长排最后 |

**推荐配置：只要至少 1 分钟的视频，最多显示 10 条**

- 最多显示链接数：`10`。
- 最低时长：`60`。
- 开启“隐藏时长未知 / 直播的视频”。
- 开启“过滤疑似广告”。
- 如果没有结果，点击“读取未知时长”补充信息，或暂时关闭“隐藏时长未知”检查候选项。

设置通过网页的 `localStorage` **按网站来源（协议、域名、端口）保存**，不是跨网站全局配置。清除网站数据会重置；隐私浏览或禁止存储时可能无法持久保存，面板会提示。脚本顶部 `DEFAULT_SETTINGS` 可以修改所有网站的初始值，已有保存设置的网站应点击“恢复默认”才能采用新默认值。

每条记录的 **“忽略”** 只在当前页面会话隐藏这条链接；底部 **“恢复本页忽略项”** 可以撤销。要长期排除一个广告来源，在设置中添加其域名或特征关键词。不要直接填写 `ad` 等过短关键词，否则可能误伤正常地址。

## 根据名称和时长确认视频

- 名称优先使用 `VideoObject` 结构化数据、播放器标签或附近标题，并标明来源；没有可靠名称时显示“地址文件名，未确认片名”。不会把整个网页的标题冒充成每个视频的片名。
- 时长优先读取匹配地址的播放器元数据，也支持页面明确标注的秒数、`01:30`、`PT1M30S`、`1分30秒`。
- 单纯从网络记录捕获、未关联播放器的链接会明确标注，不会随意套用页面上另一段视频的时长。
- **“定位”** 会收起面板并滚动到原始播放器或页面链接，不会自动播放。部分仅来自网络或结构化数据的记录没有可定位元素。
- **“复制名称＋链接”** 适合保存核对清单；下载器通常应使用不带说明文字的“复制显示链接”。

同一个视频的不同清晰度、播放清单和备用地址，可能显示为多条链接。这里限制的是**链接条数**，不是已证明互不相同的视频数量。只合并完整 URL 一致的记录，不删除签名参数，也不把参数不同的地址强行合并。

## 读取未知时长

默认扫描仅观察网页已公开的 DOM 和已加载资源，**不会主动请求候选视频**。播放器本身发出的请求不受本脚本控制。

点击单条 **“读取时长”**，或 **“读取未知时长（最多 10 条）”**，才会额外请求媒体元数据：

- 批量读取会跳过广告、关键词和手动忽略项，即使开启“隐藏未知”，也能为隐藏的未知候选补充信息；每批不超过显示上限和 10 条中的较小值，逐条执行。
- MP4 等文件使用不播放的临时 `video` 元素读取元数据；Safari 可能仍请求部分文件，`preload="metadata"` 不能保证只消耗固定字节数。
- M3U8 优先读取清单，主清单只选择一个清晰度分支，最多跟随两层子清单；每份清单限制解析大小为 512 KB，不主动下载分片来拼接文件。受到 CORS 限制时，若 Safari 支持原生 HLS，会尝试原生媒体元数据读取，这一步可能由浏览器请求部分媒体数据。
- 仅对含 `#EXT-X-ENDLIST` 的完整 HLS 清单累计分段时长。滚动直播窗口不会被当作完整视频总时长。
- MPD 读取静态清单的 `mediaPresentationDuration`；动态清单标记为直播 / 不定时长。
- 单条读取最多等待约 12 秒；点击“停止读取”、收起面板、切换到后台或离开当前地址会取消任务。读取到短于门槛的时长后，该条目会自动从显示列表消失。

读取失败时保留“时长未知”和失败原因，不会猜测时长。建议优先在原网页播放，再重新扫描。

## 哪些地址能提取

| 来源 / 类型 | 行为 |
| --- | --- |
| `video.currentSrc`、`video.src`、`source.src` | 读取 HTTP(S) 媒体地址；当前播放器时长只关联到匹配的当前地址 |
| 页面媒体链接、常见 `data-video-src` / `data-video-url` / `data-src` | 收集可识别媒体地址；忽略普通图片和普通网页链接 |
| JSON-LD `VideoObject.contentUrl`、微数据、媒体型 Open Graph | 提取媒体 URL 和页面标注的名称/时长；不把 `embedUrl` 当下载地址 |
| MP4 / M4V / MOV / WebM / OGV / MKV / FLV | 可复制识别到的链接；不保证 Safari 或下载器支持所有编码和封装 |
| M3U8 / MPD 网络资源 | 捕获网页资源记录中可识别的清单地址；不是直接的 MP4 文件 |
| `blob:` / `data:`、TS / M4S / 音频片段 / 字幕 / 密钥文件 | 不作为视频下载链接展示 |
| 同源 iframe、可访问的开放 Shadow DOM | 尽力扫描；仅顶层页面显示一个面板 |
| 跨域 iframe、关闭的 Shadow DOM | 无法直接读取内部 DOM；可尝试在播放器所在页面单独运行脚本 |

为避免大型网页占用过多资源，缓存最多 1000 条地址；单次扫描也限制处理的节点、结构化数据和嵌套根数量。它不是整站爬虫，不会自动翻页、点击播放、枚举接口、解密视频或把提取结果上传给第三方。页面内地址变化后会清理旧结果；只保存在内存中的链接不会写入设置存储。

## 有链接却下载不了

1. **清单不等于视频文件。** M3U8 / MPD 需要支持 HLS / DASH 的工具，不能仅把后缀改成 `.mp4`。
2. **链接可能过期。** 带签名或临时参数的地址，建议复制后尽快下载；脚本保留完整查询参数。
3. **下载器缺少会话信息。** 有些网站校验登录 Cookie、Referer、User-Agent 或 IP，仅复制 URL 不一定够用。本脚本不导出 Cookie，也不移除站点校验。
4. **页面没有暴露可用地址。** 跨域播放器、扩展注入限制、无后缀的私有 API、封闭播放器或 DRM，可能无法通用提取；不能保证每个 `blob:` 都能还原。
5. **疑似广告被误判。** 关闭广告过滤或清理过宽的自定义关键词，查看被过滤数量是否变化。

## 需要网站适配时提供什么

优先提供 **1–2 个具体视频页面网址**，以及正在使用的 **脚本管理器名称**。如果只有特定设备出问题，再提供 iOS / iPadOS 版本和面板现象。无需发送账号密码、Cookie 或带私人凭证的链接。

也请说明下载工具是否支持 M3U8 / MPD；如果只接受 MP4，需要另行增加格式筛选，不能把清单转换能力归给这个提取脚本。


## 阅读模式脚本

[阅读模式.user.js](./阅读模式.user.js)（3.0.0）现在是通用的阅读模式，不再只服务速读谷：任何小说 / 文章页都能一键进入干净的阅读视图。

- **入口：** 悬浮球最上方多一个 **阅** 小圆钮，轻点进入阅读模式，再轻点退出；菜单里的"阅读模式 / 退出阅读模式"是同一个开关。识别不到正文的页面（目录、首页等）不显示小圆钮，菜单项点了会提示。
- **按网站记住：** 进入一次后，本站以后的页面只要识别到正文就自动进入；主动退出则本站不再自动进入，再点一次即可恢复。速读谷的章节页默认自动进入。
- **正文识别：** 先看站点规则，再看常见小说 / 文章站的正文容器（`#content`、`#chaptercontent`、`article` 等），最后按"容器自己直接持有的文字量"评分，链接堆、导航、评论区不会被当成正文。
- **连续阅读：** 识别"下一页 / 下一章"（含 `rel=next`）自动接在后面，章节名变化时插入分隔标题；读到哪一章，地址栏就同步到哪一章，刷新、收藏、从目录再进都能对上。加载失败会给"直接打开下一页"链接。
- **进度记忆：** 按"章节地址 + 段落序号 + 段内偏移"记录，不记像素，换字号、横竖屏、拼接多章后都能回到同一段；同一本书上次读到别的章节时，顶部给出"上次读到 → 继续"，不会自动跳走。iOS Safari 切回前台把长页面重置到顶部时会拉回原位。
- **站点规则：** 速读谷保留反劫持（拦截确认过的脚本 / WebSocket / 透明诱饵层）并优先 fetch 服务端原文；hl365 保留去弹窗规则。速读谷换域名时，编辑 `阅读模式.user.js` 顶部 `SU_DOMAINS`，旧域名可保留；要给别的站加提示，在 `SITE_RULES` 里加一条即可。
- **字号 / 主题：** 沿用原来的 A− / A+ 与四种主题，设置继续生效；换字号后停在同一段。

## 常用站点脚本

[常用站点.user.js](./常用站点.user.js)（1.1.0）在悬浮球菜单里加一项 **常用站点**：面板里列出常去的网站，轻点即在新标签页打开，不用再翻书签。

- **加站点：** 面板底部直接输入名称（可不填）和网址点 **添加**，没写 `https://` 会自动补上；**把当前页加入** 一键加入当前网址。自己加的条目存在脚本自己的存储里，所有网站都能看到，适合含羞草这类经常换域名的站，可在面板里删除。固定的站也可以写在脚本顶部的 `SITES` 列表里，一行一个。
- **依赖：** 保存自定义条目需要 Userscripts 提供的 `GM.getValue / GM.setValue`；不支持的环境会隐藏该按钮，只能改脚本里的列表。

## 开发回归检查

两个脚本为了能独立安装，各自内嵌同一份共享入口代码；先运行的脚本创建入口，后运行的通过 DOM 注册功能，不要求脚本之间共享全局变量。共享入口只做通用的事：菜单项注册到 `#tool-actions`，主图标上下的 `#before` / `#after` 插槽可放各脚本自己的小圆钮（例如隐藏干扰项的回顶部 / 到底部箭头），按钮行为由注册它的脚本自己实现，因此给某个脚本加功能不需要改另一个脚本。共享入口代码块内嵌在视频嗅探、广告过滤、阅读模式、常用站点和 `nsfw_web_script.js` 五个脚本里；只有修改 `BEGIN/END shared safari tools dock` 区域本身时才需同步五份实现，测试会检查一致性，也会检查箭头代码只存在于广告过滤脚本中。

本地测试使用虚构站点和拦截的媒体请求，不访问真实视频网站：

```powershell

python -m playwright install chromium webkit
node --check 视频嗅探.user.js
node --check 广告过滤.user.js
node --check 阅读模式.user.js
node --check nsfw_web_script.js
node --check 常用站点.user.js
python tests/test_safari_tools.py --browser chromium
python tests/test_safari_tools.py --browser webkit
```

覆盖加载顺序、独立运行、无视频/动态视频/页面切换、拖动与位置恢复、上下箭头滚动、取消手势、边缘与横竖屏、存储受限、原有广告规则，以及阅读模式的进入/退出、按站记忆、段落进度、连续翻页与速读谷规则。Chromium 额外使用原生触摸输入测试拖动；桌面 WebKit 和移动视口仿真不能替代 iPhone / iPad 上的 Safari + Userscripts 真机验证。
